# Image text blend weights

`image_text_weights.bin` contains 65,536 byte-sized color blend weights, indexed
by `source_alpha * 256 + destination_alpha`. It is embedded by `text_render.rs`
and must be distributed with the source tree.

The table was generated by executing the original engine's x87 initializer at
`0x408eb0` with Unicorn in 32-bit x86 mode, using FPU control word `0x037f`, then
reading 65,536 bytes at `0xfb403c`. The source executable's SHA-256 is
`76545839bb10de0670063d92aa1797a07957f5f48e6ef2a54784a880c68a823e`.
Generating the table is not part of the build and requires no game files at build
or runtime.

Table SHA-256:
`c061812c793afcf81601d8f19e10b2f222f30a45e57f5a9d7a543784be75dc08`.

Keep the generated values: exact integer division changes some boundary values.
For example, source alpha 127 over destination alpha 255 has weight 126, and
the zero/zero entry is 255. Fully opaque source pixels bypass the table.
